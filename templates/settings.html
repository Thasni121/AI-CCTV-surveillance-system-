External notifications

Integration setup & severity

CRITICAL: restricted-zone intrusion · HIGH: loitering/crowd threshold · MEDIUM: line crossing · LOW: ordinary detections.

For email, configure environment variables CCTV_SMTP_HOST, CCTV_SMTP_PORT, CCTV_SMTP_USER, CCTV_SMTP_PASSWORD, CCTV_ALERT_EMAIL_TO and optionally CCTV_ALERT_EMAIL_FROM. For SMS configure TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, TWILIO_FROM_NUMBER and CCTV_ALERT_SMS_TO. Never put credentials in config.json or source code.

Sound alerts play in the browser when the dashboard is open; click “Enable sound alerts” once because browsers restrict autoplay. Email/SMS only work after valid provider credentials and settings are configured.

Set FR_API_KEY and configure the official Face Recognition API URL only if authorized. RTSP source entries remain a framework; continuous multi-camera streaming is not implemented in this upload-processing prototype.
